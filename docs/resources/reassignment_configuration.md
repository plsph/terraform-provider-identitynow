# identitynow_reassignment_configuration

Manages the reassignment of one work type of an identity to another identity, e.g. to forward access request approvals during an absence. Each resource manages one work type (`config_type`) of one identity; use several resources to reassign several work types.

~> **Note:** This resource uses an experimental API (`X-SailPoint-Experimental` header), which may change without notice.

## Example Usage

```terraform
resource "identitynow_reassignment_configuration" "vacation_access_requests" {
  identity_id      = "2c9180867624cbd7017642d8c8c81f67"
  config_type      = "ACCESS_REQUESTS"
  reassigned_to_id = "2c9180867624cbd7017642d8c8c81f68"
  start_date       = "2026-10-01T00:00:00Z"
  end_date         = "2026-10-15T00:00:00Z"
}
```

Dates that denote the same instant in a different format, e.g. with milliseconds or another time zone offset, do not produce a diff.

Changes of `reassigned_to_id`, `start_date` and `end_date` are applied with `PUT /reassignment-configurations/{identityId}` for the configured work type.

## Schema

### Required

- `config_type` (String) Work type to reassign: `ACCESS_REQUESTS`, `CERTIFICATIONS`, `MANUAL_TASKS` or `GENERIC_APPROVALS`. Changing this forces a new reassignment to be created.
- `identity_id` (String) ID of the identity whose work is reassigned. Changing this forces a new reassignment to be created.
- `reassigned_to_id` (String) ID of the identity that receives the work items.

### Optional

- `end_date` (String) RFC 3339 date-time at which the reassignment ends. When not set, the reassignment is permanent.
- `start_date` (String) RFC 3339 date-time from which work items are reassigned. When not set, the API default is used and kept. Equal times in a different format do not show a difference.

### Read-Only

- `created` (String) Creation date.
- `id` (String) Resource ID in the form `<identity_id>/<config_type>`.
- `modified` (String) Last modification date.

## Import

Reassignment configurations can be imported using the identity ID and the work type separated by `/`:

```shell
terraform import identitynow_reassignment_configuration.example <identity-id>/ACCESS_REQUESTS
```
