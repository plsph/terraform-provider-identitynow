# identitynow_org_config

Manages the tenant-wide organization configuration, most commonly the time zone that scheduled tasks use.

There is one org configuration per tenant, it cannot be created or deleted. Creating the resource applies the configured settings to the existing org configuration, and destroying it only removes it from Terraform state: the settings are left unchanged in IdentityNow.

Only the settings present in the configuration are managed. Settings that are not configured are never changed or reset; they show the current tenant value. Removing a setting from the configuration stops managing it and leaves its current value in place. Updates are sent as JSON Patch operations for the configured settings that changed: `replace` for settings present in the current configuration, and `add` for settings the API omits (e.g. unset ARM settings), because `replace` fails for a missing member.

`org_name` cannot be changed. `arm_auth` is sensitive; when the API does not return it, the configured value is kept in state.

## Example Usage

```terraform
data "identitynow_valid_time_zones" "all" {}

resource "identitynow_org_config" "this" {
  time_zone = "Europe/Warsaw"
}
```

All arguments are optional; settings that are not configured keep their current value.

## Schema

### Optional

- `arm_auth` (String, Sensitive) ARM authentication string. The value is sensitive. When the API does not return the value, the known value is kept in state. When not configured, the current tenant value is kept and shown.
- `arm_customer_id` (String) Access Risk Management (ARM) customer ID. When not configured, the current tenant value is kept and shown.
- `arm_db` (String) ARM database name. When not configured, the current tenant value is kept and shown.
- `arm_sap_system_id_mappings` (String) ARM mappings of IdentityNow source IDs to ARM system IDs, as returned by the API. When not configured, the current tenant value is kept and shown.
- `arm_sso_url` (String) ARM SSO URL. When not configured, the current tenant value is kept and shown.
- `iai_enable_certification_recommendations` (Boolean) Whether AI certification recommendations are enabled. When not configured, the current tenant value is kept and shown.
- `lcs_change_honors_source_enable_feature` (Boolean) Whether the LCS_CHANGE_HONORS_SOURCE_ENABLE_FEATURE flag is enabled. When not configured, the current tenant value is kept and shown.
- `sod_report_configs_json` (String) Separation of duties report columns, objects with `columnName`, `required`, `included` and `order`. Required columns cannot be changed. A JSON array, e.g. built with `jsonencode`. When not configured, the current tenant value is kept and shown.
- `time_zone` (String) Time zone of the org, e.g. `Europe/Warsaw`. It determines when scheduled tasks run. Valid values are returned by the `identitynow_valid_time_zones` data source. When not configured, the current tenant value is kept and shown.

### Read-Only

- `id` (String) Always `org-config`.
- `org_name` (String) Name of the org.

## Import

The settings can be imported with any ID; the ID is always set to `org-config`:

```shell
terraform import identitynow_org_config.this org-config
```
