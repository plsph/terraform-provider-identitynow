# identitynow_oauth_client

Manages an OAuth (API) client, for example the credentials used by a CI pipeline or an integration.

~> **Note:** The client secret is only returned by the API when the client is created. It is stored in the Terraform state as a sensitive value, so protect the state accordingly. Imported clients have no `secret`.

## Example Usage

```terraform
resource "identitynow_oauth_client" "ci" {
  name                          = "CI pipeline"
  description                   = "Used by the CI pipeline to deploy configuration"
  access_token_validity_seconds = 750
  grant_types                   = ["CLIENT_CREDENTIALS"]
  access_type                   = "OFFLINE"
  scope                         = ["sp:scopes:all"]
}

output "ci_client_secret" {
  value     = identitynow_oauth_client.ci.secret
  sensitive = true
}
```

`type`, `internal` and `scope` cannot be updated, changing them forces a new client to be created. All other arguments are updated in place.

## Schema

### Required

- `access_token_validity_seconds` (Number) Number of seconds an access token generated for this client is valid for.
- `access_type` (String) Access type, `ONLINE` or `OFFLINE`.
- `description` (String) Description of the API client.
- `grant_types` (Set of String) OAuth 2.0 grant types the client can be used with: `CLIENT_CREDENTIALS`, `AUTHORIZATION_CODE` or `REFRESH_TOKEN`.
- `name` (String) Human-readable name of the API client.

### Optional

- `business_name` (String) Name of the business the API client belongs to.
- `claims_supported` (Boolean) Whether the API client supports the serialization of SAML claims with the `AUTHORIZATION_CODE` flow. When not set, the value chosen by IdentityNow is used.
- `enabled` (Boolean) Whether the API client is enabled. Defaults to `true`.
- `homepage_url` (String) Homepage URL associated with the owner of the API client.
- `internal` (Boolean) Whether the API client can be used for requests internal to IdentityNow. Cannot be updated, changing it forces a new client to be created.
- `redirect_uris` (Set of String) Approved redirect URIs, required for the `AUTHORIZATION_CODE` grant type.
- `refresh_token_validity_seconds` (Number) Number of seconds a refresh token is valid for. When not set, the value chosen by IdentityNow is used.
- `scope` (Set of String) Scopes of the API client. Defaults to `sp:scopes:all`, which grants all rights of the identity that creates the client. Cannot be updated, changing it forces a new client to be created.
- `strong_auth_supported` (Boolean) Whether the API client supports strong authentication. When not set, the value chosen by IdentityNow is used.
- `type` (String) Client type, `CONFIDENTIAL` or `PUBLIC`. Cannot be updated, changing it forces a new client to be created.

### Read-Only

- `created` (String) Creation date.
- `id` (String) OAuth client ID, used as the client ID in OAuth flows.
- `modified` (String) Last modification date.
- `secret` (String, Sensitive) Client secret. Only available for clients created by Terraform. It is only returned when the client is created, so it is null for imported clients.

## Import

OAuth clients can be imported using their ID. The secret cannot be imported:

```shell
terraform import identitynow_oauth_client.example <client-id>
```
