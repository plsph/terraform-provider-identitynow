# identitynow_non_employee_schema_attribute

Manages a custom schema attribute of a non-employee source. Every non-employee source has 8 mandatory attributes, and up to 10 custom attributes can be added.

## Example Usage

```terraform
resource "identitynow_non_employee_source" "contractors" {
  name        = "Contractors"
  description = "External contractors"

  owner {
    id = "2c9180867624cbd7017642d8c8c81f67"
  }
}

resource "identitynow_non_employee_schema_attribute" "cost_center" {
  non_employee_source_id = identitynow_non_employee_source.contractors.id
  technical_name         = "costCenter"
  label                  = "Cost center"
  help_text              = "Cost center that pays the contractor"
  placeholder            = "CC-0000"
  required               = true
}
```

`label`, `help_text`, `placeholder` and `required` are changed with a JSON Patch of the changed fields.

## Schema

### Required

- `label` (String) Label displayed in the UI.
- `non_employee_source_id` (String) ID of the non-employee source (`identitynow_non_employee_source.id`). Changing this forces a new attribute to be created.
- `technical_name` (String) Technical name of the attribute, unique per source. It cannot be changed, changing this forces a new attribute to be created.

### Optional

- `help_text` (String) Help text displayed in the UI.
- `placeholder` (String) Hint text shown in the empty input field.
- `required` (Boolean) Whether the attribute is required for all non-employees of the source. Defaults to `false`.
- `type` (String) Attribute type. Only `TEXT` is supported for custom attributes, which is the default. Changing this forces a new attribute to be created.

### Read-Only

- `created` (String) Creation date.
- `id` (String) Schema attribute ID.
- `modified` (String) Last modification date.
- `system` (Boolean) Whether this is a mandatory system attribute.

## Import

Schema attributes can be imported using the non-employee source ID and the attribute ID separated by `/`:

```shell
terraform import identitynow_non_employee_schema_attribute.example <non-employee-source-id>/<attribute-id>
```
