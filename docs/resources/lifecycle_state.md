# identitynow_lifecycle_state

Manages a lifecycle state of an identity profile. Lifecycle states control the access and the account actions applied to identities, e.g. when they join or leave the organization.

## Example Usage

```terraform
resource "identitynow_lifecycle_state" "inactive" {
  identity_profile_id = "2b838de9-db9b-abcf-e646-d4f274ad4238"
  name                = "Inactive"
  technical_name      = "inactive"
  description         = "Identities that left the organization"
  enabled             = true
  identity_state      = "INACTIVE_LONG_TERM"

  account_actions_json = jsonencode([
    {
      action     = "DISABLE"
      allSources = true
    }
  ])
  remove_all_access_enabled = true

  email_notification_option {
    notify_managers       = true
    notify_specific_users = true
    email_address_list    = ["it-security@example.com"]
  }
}
```

## Schema

### Required

- `identity_profile_id` (String) ID of the identity profile the lifecycle state belongs to. Changing this forces a new lifecycle state to be created.
- `name` (String) Name of the lifecycle state. The API does not allow renaming, changing this forces a new lifecycle state to be created.
- `technical_name` (String) Technical name of the lifecycle state, the value of the `cloudLifecycleState` identity attribute. Changing this forces a new lifecycle state to be created.

### Optional

- `access_profile_ids` (Set of String) Set of IDs of the access profiles granted to identities that enter the lifecycle state.
- `account_actions_json` (String) Actions performed on the accounts of identities that enter the lifecycle state, as a JSON array of objects with `action` (`ENABLE`, `DISABLE` or `DELETE`) and one of `sourceIds`, `excludeSourceIds` or `allSources`. The value is compared semantically.
- `description` (String) Description of the lifecycle state.
- `email_notification_option` (Block List) Email notifications sent when an identity enters the lifecycle state, at most one block. Without the block no notifications are sent. (see [below for nested schema](#nestedblock--email_notification_option))
- `enabled` (Boolean) Whether the lifecycle state is enabled. The API defaults it to `false`.
- `identity_state` (String) Identity state associated with the lifecycle state: `ACTIVE`, `INACTIVE_SHORT_TERM` or `INACTIVE_LONG_TERM`. The API may assign one when not set. Changing this forces a new lifecycle state to be created.
- `priority` (Number) Sort order of the lifecycle state, lower numbers first. The API assigns one when not set.
- `remove_all_access_enabled` (Boolean) Whether all access is marked for removal when an identity enters the lifecycle state.

### Read-Only

- `created` (String) Creation date.
- `id` (String) Lifecycle state ID.
- `identity_count` (Number) Number of identities in the lifecycle state.
- `modified` (String) Last modification date.

### Nested Schema for `email_notification_option`

Optional:

- `email_address_list` (List of String) Email addresses notified when `notify_specific_users` is true.
- `notify_all_admins` (Boolean) Notify all admins. Defaults to `false`.
- `notify_managers` (Boolean) Notify the manager of the identity. Defaults to `false`.
- `notify_specific_users` (Boolean) Notify the users in `email_address_list`. Defaults to `false`.

## Import

Lifecycle states can be imported using the identity profile ID and the lifecycle state ID separated by a slash:

```shell
terraform import identitynow_lifecycle_state.example <identity-profile-id>/<lifecycle-state-id>
```
