# identitynow_identity_profile

Manages an identity profile. An identity profile builds identities from the accounts of its authoritative source and maps account attributes to identity attributes.

## Example Usage

```terraform
data "identitynow_identity" "owner" {
  alias = "john.doe"
}

resource "identitynow_identity_profile" "employees" {
  name        = "Employees"
  description = "Identities from the HR system"
  priority    = 10

  owner {
    id = data.identitynow_identity.owner.id
  }

  authoritative_source {
    id = "2c9180835d191a86015d28455b4a2329"
  }

  identity_attribute_config_enabled = true
  attribute_config_json = jsonencode([
    {
      identityAttributeName = "email"
      transformDefinition = {
        type = "accountAttribute"
        attributes = {
          sourceName    = "HR"
          attributeName = "mail"
        }
      }
    }
  ])
}
```

## Arguments Reference

* `name` - (Required) Name of the identity profile.
* `authoritative_source` - (Required) Authoritative source of the identity profile. Exactly one block is required. It supports:
    * `id` - (Required) Source ID.
    * `type` - (Optional) Object type, defaults to `SOURCE`.
    * `name` - (Optional) Source name. The API fills it in when not set.
* `description` - (Optional) Description of the identity profile.
* `priority` - (Optional) Priority of the identity profile. The API assigns one when not set.
* `owner` - (Optional) Owner of the identity profile, at most one block. It supports:
    * `id` - (Required) Identity ID.
    * `type` - (Optional) Object type, defaults to `IDENTITY`.
    * `name` - (Optional) Identity name. The API fills it in when not set.
* `identity_attribute_config_enabled` - (Optional) Whether the identity attribute mappings are enabled. Values are only promoted to identities when enabled. When not set, the current value is kept.
* `attribute_config_json` - (Optional) Identity attribute mappings (`identityAttributeConfig.attributeTransforms` in the API) as a JSON array of objects with `identityAttributeName` and `transformDefinition`. Use `jsonencode()` for convenience. The value is compared semantically, so formatting and key order do not produce a diff. When not set, the mappings generated by IdentityNow are kept and not managed.

The authoritative source and the identity attribute configuration cannot be changed in the same API request. When both change, the provider sends two update requests: first the source, then the mappings.

## Attributes Reference

* `id` - Identity profile ID.
* `identity_refresh_required` - Whether an identity refresh is required for the profile.
* `identity_count` - Number of identities belonging to the profile.
* `has_time_based_attr` - Whether the profile has time based attributes that require a periodic refresh.
* `identity_exception_report_task_result_id` - Task result ID of the last identity exception report.
* `identity_exception_report_name` - Name of the last identity exception report.
* `created` - Creation date.
* `modified` - Last modification date.

## Import

Identity profiles can be imported using their ID:

```shell
terraform import identitynow_identity_profile.example <identity-profile-id>
```

Deleting an identity profile starts a background task in IdentityNow; the profile disappears when the task finishes.
