# identitynow_managed_cluster_type

Manages a managed cluster type, which defines the processes that run on the [managed clusters](managed_cluster) of that type for a pod or org.

Updates are sent as JSON Patch operations for the changed attributes only.

## Example Usage

```terraform
resource "identitynow_managed_cluster_type" "custom" {
  type                = "custom-cluster"
  pod                 = "<POD>"
  org                 = "<ORG>"
  managed_process_ids = ["<MANAGED_PROCESS_ID>"]
}
```

## Schema

### Required

- `org` (String) Org the cluster type applies to.
- `pod` (String) Pod the cluster type applies to.
- `type` (String) Name of the cluster type.

### Optional

- `managed_process_ids` (List of String) IDs of the processes that run on clusters of this type. Removing the attribute clears the list.

### Read-Only

- `id` (String) Managed cluster type ID.

## Import

Managed cluster types can be imported using their ID:

```shell
terraform import identitynow_managed_cluster_type.example <cluster-type-id>
```
