# identitynow_custom_user_level

Manages a custom user level, a set of UI right sets that can be assigned to identities to grant them access to parts of IdentityNow.

~> **Note:** This resource uses an experimental API that may change without notice.

A new user level is created in `DRAFT` status. Set `publish = true` to publish it after it is created or updated, which makes it active and assignable. A published user level cannot be unpublished.

## Example Usage

```terraform
resource "identitynow_custom_user_level" "identity_managers" {
  name        = "Identity Managers"
  description = "Manage identities"
  right_sets  = ["idn:ui-identity-management-read"]
  publish     = true

  owner {
    id = "2c9180835d2e5168015d32f890ca1581"
  }
}
```

All arguments are updated in place.

## Schema

### Required

- `description` (String) Description of the user level.
- `name` (String) Name of the user level.

### Optional

- `owner` (Block List) Identity that owns the user level. Exactly one block is required. (see [below for nested schema](#nestedblock--owner))
- `publish` (Boolean) Publish the user level after it is created or updated, making it active and assignable. A published user level cannot be unpublished. Defaults to `false`, which leaves a new user level in `DRAFT` status. Setting it to `false` on a published user level has no effect.
- `right_sets` (Set of String) IDs of the right sets assigned to the user level, see [identitynow_authorization_right_sets](../data-sources/authorization_right_sets). When only a parent right set is listed, IdentityNow assigns all of its children as well. These children are listed in `assigned_right_sets` and do not produce a diff. A listed parent that IdentityNow only returns through its assigned children does not produce a diff either.

### Read-Only

- `assigned_right_sets` (Set of String) IDs of all right sets assigned to the user level, including children assigned automatically.
- `created` (String) Creation date.
- `id` (String) User level ID.
- `modified` (String) Last modification date.
- `status` (String) Status of the user level, `DRAFT` or `ACTIVE`.

### Nested Schema for `owner`

Required:

- `id` (String) Owner identity ID.

Optional:

- `name` (String) Owner display name. When not set, the name returned by IdentityNow is used. A configured name (and type) is kept in state as long as the owner `id` does not change, so a name that differs from the display name returned by IdentityNow does not produce a diff.
- `type` (String) Owner type. Defaults to `IDENTITY`.

## Import

Custom user levels can be imported using their ID. `publish` is not imported, set it in the configuration:

```shell
terraform import identitynow_custom_user_level.example <user-level-id>
```
