# identitynow_managed_client

Manages a managed client, a virtual appliance (VA) or connector gateway (CCG) registered in a [managed cluster](managed_cluster).

Name and description are updated with JSON Patch; changing the cluster or the type forces a new client.

## Example Usage

```terraform
resource "identitynow_managed_client" "va_1" {
  cluster_id  = "<CLUSTER_ID>"
  name        = "VA 1"
  description = "First virtual appliance of the primary cluster"
  type        = "VA"
}
```

## Schema

### Required

- `cluster_id` (String) ID of the managed cluster the client belongs to. Changing this forces a new client to be created.

### Optional

- `description` (String) Description of the client.
- `name` (String) Name of the client. When not set, the API generates one (`VA-<client_id>`). Since the API always has a name, removing the argument keeps the current name instead of clearing it.
- `type` (String) Client type, `VA` or `CCG`. When not set, the API default is stored. Changing this forces a new client to be created.

### Read-Only

- `alert_key` (String) Key describing any immediate client alerts.
- `api_gateway_base_url` (String) API gateway base URL of the client.
- `client_id` (String) Client ID used in API management.
- `cluster_type` (String) Type of the cluster the client belongs to.
- `created_at` (String) Creation date.
- `id` (String) Managed client ID.
- `ip_address` (String) Public IP address of the client.
- `last_seen` (String) When the client was last seen by the server.
- `provision_status` (String) Provisioning status of the client, `PROVISIONED` or `DRAFT`.
- `secret` (String, Sensitive) API key of the client. The value is sensitive. It is taken from the create response and kept in state, since the API does not return it again.
- `since_last_seen` (String) Milliseconds since the client last polled the server.
- `status` (String) Status of the client, e.g. `NORMAL`, `CONFIGURING` or `ERROR`.
- `updated_at` (String) Last update date.
- `va_download_url` (String) Virtual appliance download URL.
- `va_version` (String) Version of the virtual appliance software the client runs.

## Import

Managed clients can be imported using their ID:

```shell
terraform import identitynow_managed_client.example <client-id>
```

An imported client has no `secret` unless the API returns it.
