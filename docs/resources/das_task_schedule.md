# identitynow_das_task_schedule

Manages a Data Access Security task schedule, which runs a task such as a crawl or a permission collection of a [Data Access Security application](das_application) on a recurring schedule.

Updates replace the whole schedule (PUT) with the configured values.

## Example Usage

```terraform
resource "identitynow_das_task_schedule" "file_share_crawl" {
  task_type_name = "Crawl"
  schedule_type  = "Weekly"
  interval       = 1
  days_of_week   = ["Monday"]
  active         = true
  application_id = 42
}
```

## Schema

### Required

- `schedule_type` (String) Schedule cycle, e.g. `Daily`, `Weekly` or `Manual`.
- `task_type_name` (String) Type of the scheduled task.

### Optional

- `active` (Boolean) Whether the schedule is active. Defaults to `false`.
- `application_id` (Number) ID of the Data Access Security application of the task, e.g. `identitynow_das_application.example.id`.
- `days_of_week` (List of String) Days of the week the task runs on, e.g. `Monday`.
- `end_time` (Number) End time of the schedule, in seconds since the epoch.
- `interval` (Number) Interval between runs in units of the schedule cycle, e.g. days for a daily schedule.
- `run_after_schedule_task_id` (Number) ID of another schedule whose completion triggers this task.
- `schedule_task_name` (String) Display name of the scheduled task.
- `start_time` (Number) Start time of the schedule, in seconds since the epoch. When not set, the value returned by the API is stored and kept: the API always has a start time, so removing the argument keeps the current start time.

### Read-Only

- `created_by_display_name` (String) Display name of the user who created the schedule.
- `id` (String) Schedule ID.
- `last_run` (Number) Last run time, in seconds since the epoch.
- `next_run` (Number) Next run time, in seconds since the epoch.
- `run_after_schedule_task_name` (String) Name of the schedule whose completion triggers this task.

## Import

Data Access Security task schedules can be imported using their numeric ID:

```shell
terraform import identitynow_das_task_schedule.example <schedule-id>
```
