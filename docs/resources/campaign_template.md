# identitynow_campaign_template

Manages a certification campaign template. Campaigns can be generated from the template manually or on a schedule managed with `identitynow_campaign_template_schedule`. The template is owned by the identity the provider authenticates as.

## Example Usage

```terraform
resource "identitynow_campaign_template" "quarterly_managers" {
  name              = "Quarterly manager certification"
  description       = "Managers review the access of their reports every quarter."
  deadline_duration = "P2W"

  campaign_json = jsonencode({
    name                     = "Manager certification %TIME_PERIOD%"
    description              = "Review the access of your reports"
    type                     = "MANAGER"
    emailNotificationEnabled = true
    autoRevokeAllowed        = false
    recommendationsEnabled   = true
  })
}
```

`campaign_json` is compared with the API value on the configured fields only: formatting, key order, defaults and read-only fields IdentityNow adds (`id`, `status`, `created`, `alerts` and similar) do not produce a diff. Read-only fields are not stored in state.

## Schema

### Required

- `campaign_json` (String) Definition of the campaigns generated from the template as a JSON object: `name`, `description`, `type` (`MANAGER`, `SOURCE_OWNER`, `SEARCH`, `ROLE_COMPOSITION` or `MACHINE_ACCOUNT`), flags such as `emailNotificationEnabled`, `autoRevokeAllowed`, `recommendationsEnabled` and `sunsetCommentsRequired`, `mandatoryCommentRequirement`, `filter`, `correlatedStatus` and the type specific `searchCampaignInfo`, `sourceOwnerCampaignInfo`, `roleCompositionCampaignInfo` or `machineAccountCampaignInfo`. Campaign names and descriptions can use the placeholders documented for the campaign template generate API. Use `jsonencode()`.
- `description` (String) Template description. It has no bearing on the descriptions of generated campaigns.
- `name` (String) Template name. It has no bearing on the names of generated campaigns.

### Optional

- `deadline_duration` (String) Time period in which generated campaigns must be completed, as an ISO-8601 duration such as `P2W`. The deadline of a generated campaign is the generation date plus this duration.

### Read-Only

- `created` (String) Creation date.
- `id` (String) Campaign template ID.
- `modified` (String) Last modification date.
- `owner_ref` (Attributes List) Owner of the template and of the campaigns generated by its schedule, with `id`, `type` and `name`. Set by the API to the identity that created the template. (see [below for nested schema](#nestedatt--owner_ref))
- `scheduled` (Boolean) Whether the template has a schedule.

### Nested Schema for `owner_ref`

Read-Only:

- `id` (String) Owner ID.
- `name` (String) Owner name.
- `type` (String) Owner type.

## Update Behaviour

Updates send a JSON Patch with the changed fields only. A change of `campaign_json` replaces the whole campaign definition.

## Import

Campaign templates can be imported using their ID:

```shell
terraform import identitynow_campaign_template.example <campaign-template-id>
```
