# Data Source: identitynow_valid_time_zones

Use this data source to list the time zones that can be set as `time_zone` of the [identitynow_org_config](../resources/org_config) resource. The API is experimental; the provider sends the `X-SailPoint-Experimental` header.

## Example Usage

```terraform
data "identitynow_valid_time_zones" "all" {}

resource "identitynow_org_config" "this" {
  time_zone = "Europe/Warsaw"

  lifecycle {
    precondition {
      condition     = contains(data.identitynow_valid_time_zones.all.time_zones, "Europe/Warsaw")
      error_message = "Europe/Warsaw is not a valid time zone."
    }
  }
}
```
