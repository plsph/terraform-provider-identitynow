# Data Source: identitynow_notification_template

Use this data source to look up a custom notification template by ID, or by key, medium and locale. Only templates customized in the tenant are found, not the default templates.

## Example Usage

```terraform
data "identitynow_notification_template" "work_item_summary" {
  key    = "cloud_manual_work_item_summary"
  medium = "EMAIL"
  locale = "en"
}
```

Set either `id`, or all of `key`, `medium` and `locale`.

## Schema

### Optional

- `id` (String) Template ID. Set either `id`, or all of `key`, `medium` and `locale`.
- `key` (String) Template key. Set either `id`, or all of `key`, `medium` and `locale`.
- `locale` (String) Locale as a BCP 47 language tag, e.g. `en`. Set either `id`, or all of `key`, `medium` and `locale`.
- `medium` (String) Message medium: `EMAIL`, `SLACK` or `TEAMS`. Set either `id`, or all of `key`, `medium` and `locale`.

### Read-Only

- `body` (String) Message body.
- `created` (String) Creation date.
- `description` (String) Template description.
- `footer` (String) Deprecated footer.
- `from` (String) "From:" address.
- `header` (String) Deprecated header.
- `modified` (String) Last modification date.
- `name` (String) Template name.
- `reply_to` (String) "Reply To" address.
- `slack_template_json` (String) Slack template as a JSON object, without empty values.
- `subject` (String) Subject line.
- `teams_template_json` (String) Microsoft Teams template as a JSON object, without empty values.
