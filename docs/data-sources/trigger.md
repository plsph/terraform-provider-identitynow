# Data Source: identitynow_trigger

Use this data source to look up an event trigger available in the tenant by ID or name, e.g. to reference it in an [identitynow_trigger_subscription](../resources/trigger_subscription).

## Example Usage

```terraform
data "identitynow_trigger" "identity_created" {
  id = "idn:identity-created"
}

data "identitynow_trigger" "access_request_submitted" {
  name = "Access Request Submitted"
}
```

Exactly one of `id` and `name` must be set.

## Schema

### Optional

- `id` (String) Trigger ID, e.g. `idn:identity-created`. Exactly one of `id` or `name` must be set.
- `name` (String) Trigger name. All triggers are listed and matched by exact name. Exactly one of `id` or `name` must be set.

### Read-Only

- `description` (String) Trigger description.
- `example_input_json` (String) Example payload sent by the trigger, as a JSON document.
- `input_schema` (String) JSON schema of the payload sent by the trigger to subscribers.
- `type` (String) Trigger type: `REQUEST_RESPONSE` or `FIRE_AND_FORGET`.
