# Data Source: identitynow_source_subtype

Use this data source to look up a machine account subtype by ID, or by source ID and technical name. It uses the experimental `/source-subtypes` API.

## Example Usage

```terraform
data "identitynow_source_subtype" "service_account" {
  source_id      = "2c9180835d191a86015d28455b4a2329"
  technical_name = "service_account"
}
```

Set either `id`, or both `source_id` and `technical_name`.

## Schema

### Optional

- `id` (String) Subtype ID. Set either `id`, or both `source_id` and `technical_name`.
- `source_id` (String) ID of the source. Required together with `technical_name` when `id` is not set.
- `technical_name` (String) Technical name of the subtype. Required together with `source_id` when `id` is not set.

### Read-Only

- `created` (String) Creation date.
- `description` (String) Description of the subtype.
- `display_name` (String) Display name of the subtype.
- `modified` (String) Last modification date.
- `system_managed` (Boolean) Whether the subtype is managed by the system.
- `type` (String) Type of the subtype, `MACHINE` or null.
